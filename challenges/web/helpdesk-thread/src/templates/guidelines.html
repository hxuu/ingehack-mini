Agent guidelines

  1. Keep replies on the ticket. The customer reads the thread, not the desk note.
  2. Do not alter the customer's words. Quote the message as it was typed, then answer it.
  3. Use the desk note for what the customer must not see. The desk note appears on the agent view only.
  4. File the white copy. Send the canary. The third copy stays in the ticket book.

Desk screens work inside the customer's own ticket. Keep replies on the ticket so the customer can read them, and use the desk note only for what the customer should not see.

Tokens we keep in cookies so the front end can read them

  • agent_token: the ticket token. The reply form reads it from the cookie and sends it back in the X-Agent-Token header.

Keeping the token in a cookie means every desk screen works without a separate setup step for each browser tab.
